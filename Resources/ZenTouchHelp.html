ZenTouch

Multi-touch input for your ASUS ZenScreen Touch MB16AMTR.

Start touch input

  1. Connect the ZenScreen's USB data cable. Video alone does not carry finger contacts.
  2. Open Settings… from the ZenTouch menu bar icon.
  3. Allow Input Monitoring and Accessibility. Enable ZenTouch in macOS Settings, then quit and reopen it if requested. Green checks show the grants seen by this app.
  4. Select your ZenScreen, keep it in landscape at 0° rotation, and click Enable Touch Input.

Gestures

  • Tap with one finger to click. Move one finger to drag.
  • Move two fingers together to scroll. Tap with two fingers to right-click.
  • Hold one finger still, then lift it, for a right-click.
  • Experimental pinch is optional; compatibility varies between apps.

The menu bar

Closing Settings leaves touch input running. The checked Active menu item means touch input is running. Click it to stop or resume input. Quit ZenTouch stops input, requests the controller's previous mode, and exits.

ZenTouch remembers the chosen display and whether input was enabled. Sleep or locking pauses input; waking resumes it if the display and permissions are still available. After a USB disconnect or a display configuration change, check Settings and enable input again.

Test and troubleshoot

Test Finger Contacts previews contacts without clicking or scrolling. Report and frame counts help identify a missing USB connection or a decoding problem. Stop the test before enabling input.

Open Logs Folder opens ~/Library/Logs/ZenTouch. Logs contain touch-controller reports and translated actions. Rotation retains the current file and two 8 MiB archives. The Mac's other input devices are not recorded.

If ZenTouch is missing from macOS Privacy & Security, use the + button to add the installed app. Normal updates reuse its signing identity and do not reset permissions.

Supported hardware

This build supports the tested eGalaxTouch EXC3200-2505 controller (USB 0eef:c000) in the MB16AMTR. Clicks and two-finger scrolling have been physically verified. It does not yet provide complete Apple trackpad gesture behavior.
