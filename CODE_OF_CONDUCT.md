# Code of conduct

Discuss the work with respect. Critique behavior and code, give concrete examples, and leave room for corrections.

Harassment, discrimination, threats, personal attacks and publishing somebody else's private information are not accepted. Maintainers may remove content or restrict participation when necessary to keep the project usable.

Report a problem privately through the [maintainer's GitHub profile](https://github.com/pavkam), using an available private contact route. Do not publish private information in an issue to report a violation.
